# TaskFlow

Sistema web desenvolvido como atividade da disciplina de Desenvolvimento Web.

O **TaskFlow** é uma aplicação para gerenciamento de tarefas, permitindo visualizar, organizar e acompanhar atividades por meio de uma interface web.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Visualização de tarefas
* Cadastro de tarefas
* Organização das atividades
* Página sobre o sistema
* Interface web responsiva
